# System Design Specifications Directory

This directory stores hardened architectural and technical designs produced via Skill 02 (`02-technical-design.md`).

## Naming Convention
- Files must be named `SPEC-[epic_id]-[domain].md` (e.g. `SPEC-EPIC-001-auth.md`).
- Must strictly use the template `.ai/templates/02-system-design-spec.md`.
- Requires status `tech_approved` before advancing to code execution.
