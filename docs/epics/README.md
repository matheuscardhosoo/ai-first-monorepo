# Epics Directory

This directory stores business initiatives and requirements defined via Skill 01 (`01-business-discovery.md`).

## Naming Convention
- Files must be named `EPIC-[id].md` (e.g. `EPIC-001.md`).
- Must strictly use the template `.ai/templates/01-epic-intent.md`.
- Requires status `product_approved` before advancing to technical architecture.
