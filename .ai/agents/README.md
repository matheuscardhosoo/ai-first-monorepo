# Agent Roles & Personas Directory

This directory defines specialized agent personas and configurations for multi-agent platforms (e.g., Gemini Antigravity, Claude Code, CrewAI, AutoGen, MetaGPT).

## Defined Roles

| Role | Skill | Focus |
| :--- | :--- | :--- |
| **Product Manager** | `01-business-discovery.md` | Problem definition, anti-contamination, BDD criteria |
| **Staff Architect** | `02-technical-design.md` | Failure modes, monorepo boundaries, interface contracts |
| **Senior Engineer** | `03-development-execution.md` | Lock acquisition, safe implementation, TDD |
| **QA Automation Lead** | `04-test-validation.md` | Unit test isolation, adversarial edge cases |
| **Gatekeeper** | `05-code-review-governance.md`| Dual-alignment PR audit, security, lock release |
| **SRE / Healer** | `06-maintenance-observability.md`| Reproduction test first, 5-Whys RCA, memory loop |
| **Evaluator** | `07-continuous-evaluator.md` | Tech debt audit, AI smell detection, refactoring proposals |
